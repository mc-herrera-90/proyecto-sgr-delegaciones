## Objetivo de la documentación

Esta documentación está orientada a los **usuarios finales del SGR** y busca facilitar el aprendizaje y uso de las funcionalidades disponibles.

En cada sección se describen los procedimientos necesarios para realizar las tareas habituales dentro del sistema.
